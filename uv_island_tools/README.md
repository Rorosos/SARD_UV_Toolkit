# UV Island Tools

Расширение для Blender 5.3 и новее. Упаковывает UV-острова, проверяет их растяжение, подбирает схожие по топологии острова и сохраняет Snap-группы и кластеры.

## Установка и работа

1. Откройте **Edit → Preferences → Get Extensions → Install from Disk** и выберите `uv_island_tools-1.4.0.zip`.
2. Выделите меш, перейдите в **Edit Mode** и откройте **UV Editor**. Нажмите `N` и выберите вкладку **UV Island Tools**.
3. Выберите один остров и нажмите **Выбрать схожие**. Расширение сравнит количество и связи UV-вершин на границе и внутри островов. **Допуск** задаёт максимальное отклонение вершин в процентах от диагонали эталона.
4. Нажмите **Snap**, чтобы поместить соответствующие UV-вершины похожих выделенных островов точно в координаты эталона. **Снять Snap** отменяет групповую упаковку с наложением.
5. Кнопки **Поворот**, **Размер** и **Положение** переключают соответствующие фиксации. Фиксация положения удерживает геометрический центр. Кнопки учитывают выделенные острова, а упаковка и Snap применяют ограничения всей группы.
6. Выберите разрешение, отступы и число проходов и нажмите **Упаковать острова**. Упаковка ищет раскладку в тайле 0–1. `Esc` отменяет поиск, `Ctrl+Z` отменяет применённый результат.

## Кластеры

Раскройте **Кластеры UV** на вкладке **UV Island Tools**. Выделите острова и нажмите **Объединить в кластер**. Этой же кнопкой можно добавить острова или слить кластеры. Для этого выделите новых участников и хотя бы один остров из каждого нужного кластера.

В таблице доступны **Выделить кластер** и **Расформировать**. **Убрать выделенные** удаляет из кластера только выбранных участников. Для просмотра кластеров после открытия Blender или смены UV-карты обновите список кнопкой со стрелкой.

Упаковщик поворачивает, перемещает и масштабирует кластер целиком. Относительная раскладка его островов сохраняется. Фиксация отдельного участника ограничивает весь кластер. Зазор проверяется между кластером и другими единицами упаковки. Snap-группы можно включать в кластеры. Для нового Snap между участниками сначала уберите их из кластеров.

## Растяжение UV

На отдельной вкладке **UV Stretch** укажите **Порог** и нажмите **Найти растянутые острова**. Таблица показывает все видимые острова с растяжением от порога включительно. Кнопка с глазом исключает остров из автовыделения и оставляет его в таблице. Пометка сохраняется в меше для текущей UV-карты. Чтобы пересчитать значения после правок UV, запустите поиск ещё раз.

Процент показывает, насколько масштаб UV в наиболее растянутом направлении больше масштаба в наименее растянутом. Для каждого острова берётся максимум по треугольникам с учётом пропорций текстуры. `0%` означает одинаковый масштаб по направлениям. Схлопнутый UV-треугольник даёт `∞`.

## Настройки упаковки

| Разрешение | Зазор между островами | Поле от края |
|---|---:|---:|
| 512 × 512 | 4 px | 2 px |
| 1024 × 1024 | 8 px | 4 px |
| 2048 × 2048 | 16 px | 8 px |
| 4096 × 4096 | 32 px | 16 px |
| 8192 × 8192 | 64 px | 32 px |

Оба отступа задаются как минимумы и редактируются независимо. Для прямоугольной текстуры выберите **Своё разрешение** и задайте ширину и высоту. Зазор измеряется между UV-формами в пикселях. Вогнутые области и отверстия могут принимать другие острова, если соблюдается зазор. Заполнение — приблизительная доля площади тайла, занимаемая упакованными островами. Для Snap-группы берётся площадь её крупнейшего участника.

Размеры островов без фиксации приводятся к общей плотности по 3D-площади. Для кластера рассчитывается один коэффициент на всех участников. Настройка **Общий масштаб** разрешает дополнительно увеличивать или уменьшать свободные острова и кластеры для заполнения тайла.

**Проходы** задают число попыток поиска от 1 до 1000. Начальное значение — **100**. Упаковщик строит допустимую стартовую раскладку со случайными позициями, если текущая не подходит. Затем он варьирует позиции, углы и порядок размещения. При включённом общем масштабировании побеждает допустимая раскладка с самым большим общим масштабом из проверенных. При равном масштабе выигрывает меньший прямоугольник размещения. Если требуется, выполняются дополнительные старты с соблюдением фиксаций и отступов.

Упаковщик ищет свободные прямоугольники между островами и пробует стыковку по рёбрам контуров, в том числе внутри отверстий. Если очередной остров не помещается во второй половине прохода, упаковщик пробует переставить его перед двумя предыдущими. После поиска он повторно размещает часть островов, чтобы заполнить пропуски и сократить габариты. Если все острова допускают перенос и масштабирование и тайл свободен от препятствий, раскладку можно целиком увеличить до границ тайла с учётом padding.

По умолчанию выбран режим **Авто**. На Windows x64 он предпочитает нативный CPU для небольших задач. Для крупных партий пробует прямой **CUDA** на совместимом драйвере NVIDIA. **GPU Blender** использует вычислительный шейдер OpenGL или Vulkan. **CPU + GPU** проверяет короткий список позиций на CPU и передаёт сложные партии шейдеру Blender. **CPU** выбирает нативный модуль при наличии и использует обычный CPU-код при сбое. Для запуска CUDA достаточно совместимого драйвера NVIDIA и PTX из архива. Итоговая строка показывает использованный бэкенд, масштаб и время.

Snap допускает перенос, поворот и равномерное масштабирование в пределах фиксаций. Чтобы изменить группу после ручной правки, используйте **Снять Snap**, затем снова **Snap**. Метки хранятся по имени UV-карты. Если вы переименовали карту, верните прежнее имя для доступа к её меткам. Для групп и кластеров с участниками в разных объектах откройте все нужные UV-карты в режиме редактирования.

## Исходники

- `__init__.py` регистрирует расширение.
- `operators.py` содержит панель, команды Blender и настройки сцены.
- `blender_data.py` выделяет острова по UV-связности и хранит фиксации, группы, кластеры и игнорирование на гранях меша.
- `geometry.py` сравнивает UV-топологию, рассчитывает преобразования и измеряет растяжение.
- `island_ui.py` содержит таблицы кластеров и растяжения.
- `packing.py` генерирует раскладки, рассчитывает стыковку по контурам и проверяет пересечения и зазоры. `gpu_backend.py` параллельно проверяет те же кандидаты по треугольникам UV-граней.
- `cuda_backend.py` запускает CUDA через Driver API. `native_cpu.py` загружает модуль Windows x64. Оба используют исходник `cuda_geometry.cu` для проверки позиций и проходят дополнительную проверку итоговых UV в Python.

### Пересборка

Запустите команды Blender из папки с `blender_manifest.toml`.

```powershell
blender --command extension validate
blender --command extension build
```

Для пересборки вычислительных модулей откройте консоль Visual Studio x64 с установленным CUDA Toolkit.

```powershell
nvcc -ptx -arch=compute_75 --fmad=false cuda_geometry.cu -o cuda_geometry.ptx
cl /O2 /fp:precise /std:c++17 /EHsc /MT /LD /TP cuda_geometry.cu /link /OUT:uvit_cpu_win64.dll
```
