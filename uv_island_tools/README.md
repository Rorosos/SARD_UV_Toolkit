# UV Island Tools

Расширение для Blender 5.3 и новее. Ищет плотную раскладку UV-островов с помощью непрерывных позиций и углов, находит похожие UV-контуры и сохраняет группы совмещённых островов.

## Установка и работа

1. Откройте **Edit → Preferences → Get Extensions → Install from Disk** и выберите `uv_island_tools-1.3.0.zip`.
2. Выделите меш, перейдите в **Edit Mode** и откройте **UV Editor**. Нажмите `N` и выберите вкладку **UV Island Tools**.
3. Выберите один остров и нажмите **Выбрать схожие**. Параметр **Допуск** задаёт максимальное отклонение контуров от эталона в процентах от его диагонали.
4. Нажмите **Snap**, чтобы наложить похожие выделенные острова. Эталон сохраняет координаты. Нажмите **Снять Snap**, чтобы дальше упаковывать членов группы отдельно.
5. Кнопки **Поворот**, **Размер** и **Положение** переключают соответствующие фиксации. Фиксация положения удерживает геометрический центр. Кнопки учитывают выделенные острова, а упаковка и Snap применяют ограничения всей группы.
6. Выберите разрешение, отступы и число проходов и нажмите **Упаковать острова**. Упаковка ищет раскладку в тайле 0–1. `Esc` отменяет поиск, `Ctrl+Z` отменяет применённый результат.

## Настройки упаковки

| Разрешение | Зазор между островами | Поле от края |
|---|---:|---:|
| 512 × 512 | 4 px | 2 px |
| 1024 × 1024 | 8 px | 4 px |
| 2048 × 2048 | 16 px | 8 px |
| 4096 × 4096 | 32 px | 16 px |
| 8192 × 8192 | 64 px | 32 px |

Оба отступа задаются как минимумы и редактируются независимо. Для прямоугольной текстуры выберите **Своё разрешение** и задайте ширину и высоту. Зазор измеряется между UV-формами в пикселях. Вогнутые области и отверстия могут принимать другие острова, если соблюдается зазор. Заполнение — приблизительная доля площади тайла, занимаемая упакованными островами. Для Snap-группы берётся площадь её крупнейшего участника.

**Проходы** задают число попыток поиска от 1 до 1000. Начальное значение — **100**. Попытки варьируют позиции, углы и порядок размещения. При включённом масштабировании упаковщик выбирает допустимую раскладку с самым большим общим масштабом из проверенных. При равном масштабе побеждает меньший прямоугольник размещения. Исходная раскладка тоже участвует в сравнении, если соблюдает отступы. Исходные формы и настройки задают воспроизводимую последовательность случайных вариантов.

Упаковщик ищет свободные прямоугольники между островами и пробует стыковку по рёбрам контуров, в том числе внутри отверстий. Если очередной остров не помещается во второй половине прохода, упаковщик пробует переставить его перед двумя предыдущими. После поиска он повторно размещает часть островов, чтобы заполнить пропуски и сократить габариты. Если все острова допускают перенос и масштабирование и тайл свободен от препятствий, раскладку можно целиком увеличить до границ тайла с учётом padding.

По умолчанию выбран режим **Авто**. На Windows x64 он предпочитает нативный CPU для небольших задач. Для крупных партий пробует прямой **CUDA** на совместимом драйвере NVIDIA. **GPU Blender** использует вычислительный шейдер OpenGL или Vulkan. **CPU + GPU** проверяет короткий список позиций на CPU и передаёт сложные партии шейдеру Blender. **CPU** выбирает нативный модуль при наличии и использует обычный CPU-код при сбое. Для запуска CUDA достаточно совместимого драйвера NVIDIA и PTX из архива. Итоговая строка показывает использованный бэкенд, масштаб и время.

Snap сравнивает текущие UV-контуры, разрешает перенос, поворот и равномерный масштаб. Допустимы разные разбиения на грани и дополнительные вершины на том же контуре. Чтобы изменить группу после ручной правки, используйте **Снять Snap**, затем снова **Snap**. Метки хранятся по имени UV-карты. Если вы переименовали карту, верните прежнее имя для доступа к её меткам. У Snap-групп с участниками в разных объектах откройте все нужные UV-карты в режиме редактирования.

## Исходники

- `__init__.py` регистрирует расширение.
- `operators.py` содержит панель, команды Blender и настройки сцены.
- `blender_data.py` выделяет острова по UV-связности и сохраняет фиксации и группы на гранях меша.
- `geometry.py` сравнивает контуры и рассчитывает допустимые преобразования.
- `packing.py` генерирует раскладки, рассчитывает стыковку по контурам и проверяет пересечения и зазоры. `gpu_backend.py` параллельно проверяет те же кандидаты по треугольникам UV-граней.
- `cuda_backend.py` запускает CUDA через Driver API. `native_cpu.py` загружает модуль Windows x64. Оба используют исходник `cuda_geometry.cu` для проверки позиций и проходят дополнительную проверку итоговых UV в Python.

### Пересборка

Запустите команды Blender из папки с `blender_manifest.toml`.

```powershell
blender --command extension validate
blender --command extension build
```

Для пересборки вычислительных модулей откройте консоль Visual Studio x64 с установленным CUDA Toolkit.

```powershell
nvcc -ptx -arch=compute_75 --fmad=false cuda_geometry.cu -o cuda_geometry.ptx
cl /O2 /fp:precise /std:c++17 /EHsc /MT /LD /TP cuda_geometry.cu /link /OUT:uvit_cpu_win64.dll
```
